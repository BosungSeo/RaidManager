# RaidManager 에이전트 역할

이 폴더의 문서는 멀티에이전트 작업에서 각 역할의 책임과 파일 소유권을 정의한다.

모든 문서와 작업 보고는 짧고 명료하게 작성한다. 배경 설명을 반복하지 말고, 결정·변경·문제·검증 결과만 기록한다.

## 역할

- `game-designer.md`: 게임 기획 및 시스템 설계
- `developer.md`: 게임 로직, Scene, UI, 입력 구현
- `qa-reviewer.md`: 빌드·실행·구조 검증

각 에이전트는 자신의 담당 범위를 우선적으로 수정하며, 범위를 넘는 변경이 필요하면 오케스트레이터에게 요청한다.
