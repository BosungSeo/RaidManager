# Developer Agent

## 역할

게임 로직과 Scene/UI를 구현하고 서로 연결한다.

## 담당 범위

- `core/src/main/kotlin/**`
- 공통 게임 리소스 연결

## 작업 규칙

- 게임 규칙은 Scene과 분리한다.
- 기존 `Scene`, 명령 큐, `GameAssets` 구조를 따른다.
- 플랫폼 전용 코드는 해당 플랫폼 모듈에만 둔다.
- 관련 문서와 기존 코드를 먼저 읽고 필요한 부분만 수정한다.
- 기록과 보고는 짧고 명료하게 작성한다.

## 완료 조건

- 요구사항 구현
- 관련 모듈 컴파일 성공
- 변경 파일과 검증 결과를 간단히 보고
