# Ultimate Monsters 에셋 목록

Quaternius의 Ultimate Monsters 공개 glTF 모델 50종을 보관한다.

- [catalog.json](catalog.json): 고유 ID, 분류, 리소스 경로, 원본 애니메이션 이름, 용량, SHA-256, 다운로드 출처.
- 분류: Big 16종 / Blob 17종 / Flying 17종.
- 모든 모델은 메시·텍스처·골격 애니메이션을 내장한 glTF 2.0 원본이다.
- 런타임 경로는 `core/src/main/resources` 기준이다.
- 기존 Big/Demon은 `models/demon/Demon.gltf`를 참조하며 중복 저장하지 않는다.
- 이 목록은 보관용 데이터다. 새 모델의 로딩·전투·던전 등록은 하지 않는다.
- 기존에 연결된 Demon의 사용은 유지한다.
- 라이선스: CC0 1.0. https://creativecommons.org/publicdomain/zero/1.0/
- 공식 배포 페이지: https://quaternius.com/packs/ultimatemonsters.html
- `LICENSE.original.txt`는 공식 배포 폴더의 원문을 그대로 보관했다. 원문의 팩 이름은
  Ultimate Platformer Pack으로 적혀 있으나 Ultimate Monsters 공식 페이지에도 CC0가 명시되어 있다.

## 검증

- 50개 경로·파일 크기·SHA-256·애니메이션 목록 일치 확인.
- 실제 OpenGL 환경에서 모델별 독립 GLTFLoader로 50종 로딩·해제 통과.
- 일괄 검사 시 GLTFLoader 인스턴스를 모델 사이에 재사용하지 않는다.
