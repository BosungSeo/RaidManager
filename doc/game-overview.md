# 게임 개요

상태: 초안

## 기본 정보

- 프로젝트명: RaidManager
- 장르: 레이드 운영/관리 게임
- 지원 플랫폼: Android, macOS 데스크톱
- 기술: Kotlin, libGDX

## 핵심 컨셉

플레이어가 레이드 팀을 구성하고, 전투와 자원 및 진행 상황을 관리하는 게임을 목표로 한다.

세부 세계관, 플레이어 역할, 레이드 규모와 승리 조건은 개발 과정에서 확정한다.

## 핵심 플레이 루프

1. 레이드 또는 게임 세션을 시작한다.
2. 팀과 전투 준비를 관리한다.
3. 레이드 진행 중 발생하는 상황에 대응한다.
4. 결과와 보상을 확인한다.
5. 다음 레이드를 준비한다.

## 현재 구현 범위

- 인트로 화면
- 메인 메뉴
- 새 게임 진입
- 프로토타입 게임 화면
- ESC 키를 통한 메인 메뉴 복귀

## 확정이 필요한 항목

- 플레이 방식: 실시간, 턴제 또는 혼합
- 플레이어가 직접 조작하는 대상
- 팀원/캐릭터의 능력치와 역할
- 레이드 실패 및 성공 조건
- 저장 슬롯과 저장 시점
- 재화, 장비, 보상 구조
