# 게임 개요

상태: 프로토타입 구현 반영

## 기본 정보

- 프로젝트명: RaidManager
- 장르: 레이드 운영/관리 게임
- 지원 플랫폼: Android, macOS 데스크톱
- 기술: Kotlin, libGDX

## 핵심 컨셉

플레이어가 직접 싸우는 대신 공격대를 구성하고, 자동 전투 결과를 분석해 다음 전략을 수정하는 레이드 운영 게임이다.

핵심 경험은 `공대 구성 → 캐릭터 세팅 → 던전 선택 → 자동 전투 → 결과 분석 → 보상과 성장 → 전략 수정`의 반복이다.

## 핵심 플레이 루프

1. 공격대에 캐릭터 3명을 편성한다.
2. 캐릭터의 장착 스킬과 아이템을 설정한다.
3. 던전을 선택하고 자동 전투를 시작한다.
4. 전투 로그와 통계를 통해 승패 원인을 확인한다.
5. 보상과 성장 요소를 반영하고 조합을 수정해 재도전한다.

## 현재 구현 범위

- 인트로 화면
- 메인 메뉴
- 새 게임 진입
- 6명 중 3명을 선택하는 공격대 편성
- 특성이 다른 던전 3개 선택
- 역할별 스킬과 던전 기믹이 적용되는 자동 전투
- 피해·회복·받은 피해·스킬 사용 통계와 실패 원인 분석
- 같은 던전 재도전 또는 공격대 재편성
- 전투 화면에서 캐릭터, 보스, 피격·회복·보호막·광역 공격 이펙트 관전

현재 구현은 스킬·아이템 세팅과 성장·보상을 제외한 핵심 전투 루프의 프로토타입이다. 캐릭터와 보스는 전투 사건에 반응해 움직이며, 전투 계산과 화면 연출은 분리되어 있다.

## MVP 목표

- 보유 캐릭터 6명, 출전 인원 3명
- Tank, Healer, DPS, Support의 4개 역할
- 캐릭터당 2~3개 스킬
- 서로 다른 대응을 요구하는 던전 3개와 보스 1종
- 자동 전투, 시간 제한, 전투 로그와 핵심 통계
- 최소한의 성장 재화와 보상

MVP는 콘텐츠 양보다 다음 가설을 검증하는 데 목적이 있다.

1. 공격대 조합을 바꾸는 과정이 재미있는가?
2. 전투 결과만 보고 실패 원인을 이해할 수 있는가?
3. 전략을 수정해 재도전하고 싶은가?
