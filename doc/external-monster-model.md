# 외부 3D 몬스터

- Quaternius Ultimate Monsters의 CC0 Demon 모델을 사용한다.
- DEMON SANCTUM을 던전 선택 첫 항목으로 추가한다.
- 체력 650, 공격력 14, 공격 간격 2초, 이동 속도 90, 광역 공격 간격 7초.
- 기존 BURST 전투 규칙과 colossus 배경을 재사용한다.
- GameAssets가 glTF 모델·텍스처·프레임버퍼를 생성하고 해제한다.
- 원본 Idle/Walk/Punch/HitReact/Death 애니메이션을 전투 상태에 맞춰 샘플링한다.
- 모델 출처와 라이선스는 resources/models/demon/README.md에 기록한다.
