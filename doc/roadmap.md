## 작업 시 우선순위

1. 전투 규칙과 상태 모델 확정
2. 화면과 분리된 전투 시뮬레이터 구현
3. `편성 → 던전 선택 → 자동 전투 → 결과 분석` 수직 슬라이스 완성
4. 조합 변경 후 재도전이 의미 있는지 검증
5. 최소 보상·성장과 저장/불러오기 연결
6. UI와 플랫폼별 사용성 개선

## MVP 완료 기준

- 세 역할 이상이 서로 다른 선택지를 제공한다.
- 세 던전이 서로 다른 대응 조합을 요구한다.
- 전투 결과에 피해량, 회복량, 사망 원인과 주요 사건이 표시된다.
- 플레이어가 결과를 보고 조합을 바꿔 재도전할 수 있다.
- 동일한 전투 입력과 시드로 결과를 재현할 수 있다.
