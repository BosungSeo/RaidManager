# 전투 피로도

- 살아 있는 공대원은 전투 시작부터 초당 피로도 0.5%p를 누적한다. 사망·전투 종료 시 멈추고 새 전투에서 초기화한다.
- 탱커: 기본 최대 HP의 0.5%를 매초 현재 HP에서 소모한다. 최대 HP는 유지하며 회복 가능하다. HP가 0이 되면 사망한다. 보호막으로 막을 수 없으며 피격 효과·적 피해 통계에는 포함하지 않는다.
- 딜러: 스킬 피해만 초당 기본값의 0.5%p 감소한다. 평타·후방 배율은 유지한다.
- 힐러: 회복 스킬의 회복량이 초당 기본값의 0.5%p 감소한다. 실제 회복량과 위협은 대상의 잃은 HP로 제한한 결과를 사용한다.
- 서포터: 기본 시전 시간 0.6초에 피로도 비율을 더한다. 예: 40초에 0.72초. 시전 시작 시 시간을 확정하며 시전 중 이동·평타·다른 스킬을 멈춘다. 완료 후 기존 쿨다운이 시작되고 사망·전투 종료 시 취소된다.
- 피로도는 최대 70%다. 딜러·힐러 효율 하한 30%, 서포터 시전 상한 1.02초다. 탱커 HP 소모는 일정하게 계속된다.
- 몬스터의 피해·회복·시전 시간에는 피로도를 적용하지 않는다.
- 고정 HUD의 각 공대원 행에 FATIGUE와 역할별 수치를 표시한다. 탱커는 초당 HP 소모·누적 손실, 딜러·힐러는 남은 효율(%), 서포터는 시전 시간·시전 중 남은 시간을 표시한다.
- 계수는 `BattleFatigue`에서 조절한다. 전투 시뮬레이터가 계산한 스냅샷을 UI에서 표시한다.
