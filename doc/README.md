# RaidManager 문서

이 폴더는 RaidManager의 게임 기획, 시스템 설계, 기술 구조와 결정 사항을 기록한다.

## 문서 목록

- [게임 개요](game-overview.md): 게임의 목표, 핵심 플레이와 용어
- [통합 게임 기획](GAME_DESIGN.md): 자동 전투 기반 공격대 운영의 전체 기획과 MVP 범위
- [시스템 설계](system-design.md): 게임 시스템의 구성과 동작 규칙
- [기술 구조](technical-architecture.md): 코드 구조, Scene 흐름과 플랫폼 구성
- [개발 로드맵](roadmap.md): 현재 상태와 다음 구현 단계

## 문서 작성 원칙

- 구현된 내용과 기획 단계의 내용을 구분해서 작성한다.
- 시스템 규칙이 바뀌면 관련 문서와 변경 이유를 함께 갱신한다.
- 숫자, 제한, 상태 전이 등 구현에 영향을 주는 값은 가능한 한 명시한다.
- 확정되지 않은 내용은 `미정` 또는 `초안`으로 표시한다.
- 핵심 재미를 검증하는 작은 수직 슬라이스를 우선하며, 콘텐츠 확장은 검증 결과에 따라 결정한다.
