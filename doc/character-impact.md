# 3D 캐릭터 전투 연출

- CharacterMotion에서 공격 0.42초, 피격 0.18초를 정의하며 골격 동작과 화면 반동이 공유한다.
- 실제 체력 피해가 있는 HIT만 피격 동작·붉은 틴트를 발생시킨다. 완전 방어 시 피격 반동은 없다.
- 타격자의 화면 위치 반대 방향으로 3~8픽셀 반동을 주며 피해량에 따라 강도가 달라진다.
- 2D 시절의 달리기 상하 흔들림·전체 이미지 기울기·늘어남은 제거하고 원본 골격 동작을 사용한다.
- 공격 전진은 최대 4픽셀, 붉은 피격 틴트는 0.18초 안에 원래 색으로 복귀한다.
- 타격·발사·보호막 중심은 발에서 46픽셀 높이, 이름은 104픽셀 높이다.
- 스킬 이미지와 투사체 크기를 줄여 캐릭터 실루엣을 덜 가린다.
- 피해 판정·능력치·스킬 효과·전투 시간은 변경하지 않는다.
- 시뮬레이터가 피해 이벤트를 보낸 뒤 투사체가 그려지는 기존 구조는 유지한다. 완전한 선행 공격 예고는 별도 변경이다.

피격 단위 테스트와 기존 회귀 테스트 통과. 실제 GameScene에서 두 팀·720프레임 렌더링을 확인했다.
